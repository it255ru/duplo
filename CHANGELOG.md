# Changelog

## 0.3.0 — 2026-09-25

Безопасность данных:
- Режимы удаления работают по схеме plan / apply. План проверяется на
  инвариант «в каждой группе остаётся минимум одна копия»; при нарушении
  ничего не удаляется, exit 2 (F-002).
- Перед удалением каждый файл сверяется с сохраняемой копией: тип, размер,
  mtime, побайтовое сравнение. При расхождении шаг пропускается (F-007).
- `shutil.rmtree` удалён. Каталог удаляется через `os.rmdir` только после
  удаления его файлов по плану (F-001).
- `--find-identical-dirs` учитывает только каталоги без подкаталогов, все
  файлы которых являются дубликатами (F-001).
- Symlink, FIFO, сокеты и устройства пропускаются; пустые файлы не
  считаются дубликатами; hardlink'и схлопываются (F-004, F-006, F-013).
- Ручной выбор (`[m]`) проверяет ввод и переспрашивает; `[A]` работает
  (F-003, F-009).

Кэш:
- JSON вместо pickle, атомарная запись, права 0600 (F-005, F-012).
- Путь по умолчанию: `$XDG_CACHE_HOME/duplo/hash_cache.json`
  (`%LOCALAPPDATA%\duplo\hash_cache.json` на Windows), а не текущий каталог.
- Новый флаг `--no-cache`.

CLI:
- Exit codes: 0 успех, 1 ошибки удаления, 2 неверный ввод или план,
  130 прерывание (F-011).
- `--interactive` и `--auto-first` взаимоисключающие.
- «Первая копия» — первая по отсортированному пути, а не по порядку
  обхода ФС.
- Ошибки чтения выводятся в конце отчёта (F-011).
- Управляющие символы в путях экранируются (F-018).
- Хеш BLAKE2b с `usedforsecurity=False` (F-017).

Несовместимые изменения:
- Удалён `--workers` (F-010). Вызов с ним завершается с exit 2.
- Старые `hash_cache.pkl` не читаются.
- Минимальная версия Python: 3.9.
